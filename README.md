# HoneyTreats — Bakery & Sweets Web Storefront

A responsive bakery and confectionery storefront website (`Sweety | HoneyTreats`) built with semantic HTML5 and custom CSS3, featuring product showcases, interactive hover transitions, customer reviews, baking blog highlights, service features, and newsletter/footer sections.

## Project Structure
- `index.html`: Main storefront markup covering the header, navigation & dropdowns, promotional offer banner, hero showcase, featured categories, trending treats grid, customer testimonial, recommended items, baking news, service highlights, and footer.
- `css/style.css`: Custom layout, typography, hover effects, product card styling, and responsive grid rules.
- `css/all.css` & `webfonts/`: Bundled icon stylesheet and webfont files (`fa-brands`, `fa-regular`, `fa-solid`) alongside Font Awesome support.
- `images/`: Bakery photography, product thumbnails, logo assets, and visual banners.

## Key Sections & Features
- **Top & Main Header:** Quick links (`About Us`, `Our Menu`, `FAQ`, `Careers`, `My Orders`, `Track Order`), social icons, brand logo, category navigation (`Home`, `Cakes`, `Cookies`, `Oriental Sweets`, `Contact Us`), a `More` dropdown (`Login`, `Cart`, `Order Details`, `Checkout`, `Baking Tips`, `Recipe Details`), cart/user/search icons, and a first-order discount offer bar.
- **Hero & Featured Highlights:** Main call-to-action banner (`Delicious Cakes & Cookies`) followed by spotlight cards (`Cinnamon Dream Cake`, `Frosted Bundt Bliss`, `Pastel Donut Paradise`).
- **Trending Treats & Recommended Products:** Interactive product cards with hover descriptions, pricing, quick-action icons (cart, wishlist, view), serving/lead-time/allergen details, and category filters (`Cakes`, `Cookies`, `Donuts`, `Pastries`).
- **Customer Testimonial, Baking News & Store Features:** Featured customer review, baking tips/articles (`How to Make Perfect Macarons`, `Decorating Cakes with Fresh Fruit`, `Creative Donut Toppings`), delivery/payment/ingredient/support highlights, newsletter sign-up, and store contact details.

## Built With
- **HTML5**
- **CSS3** (`css/style.css`, `css/all.css`)
- **Google Fonts** (`Cookie`, `Poppins`, `Jost` fallback) & **Font Awesome** icons

## How to Run
1. Extract the project folder (`HoneyTreats-Project-master`) while keeping `css/`, `images/`, and `webfonts/` in their relative paths.
2. Open `index.html` directly in any modern web browser, or serve the directory using a local development server (such as VS Code **Live Server**).
